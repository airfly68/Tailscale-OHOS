# 最佳实践处理批次

本文件仅规划最佳实践文档的处理批次，不包含规则提取、规则解释或应用代码变更。文件名采用 `document-manifest.md` 中 HTML 文件名的主题前缀，以避免重复的站点标题和采集时间掩盖主题。

## 推荐总顺序

`B01 → B02 → B03 → B04 → B05`

## B01：多端产品与体验基线

- **Batch ID：** B01
- **文件：**
  - `一次开发，多端部署概览-一次开发，多端部署.html`
  - `从一个例子开始-一次开发，多端部署.html`
  - `多设备体验设计-一次开发，多端部署.html`
- **主题：** 一次开发、多端部署的背景、端到端示例和多设备体验设计原则。
- **与其他批次的依赖关系：** 为 B02 至 B05 提供产品目标和体验判断标准；不依赖其他批次。
- **推荐处理顺序：** 首批处理；文件内按“概览 → 示例 → 体验设计”顺序。

## B02：应用架构与数据安全边界

- **Batch ID：** B02
- **文件：**
  - `架构概览-应用架构.html`
  - `分层架构设计-应用架构.html`
  - `模块化设计-应用架构.html`
  - `应用数据安全-安全设计.html`
- **主题：** 应用架构全景、分层职责、模块边界与数据安全设计。
- **与其他批次的依赖关系：** 以 B01 的多端目标为输入；为 B03 至 B05 的窗口、布局和功能适配确定可保留的架构与数据边界。
- **推荐处理顺序：** 在 B01 后处理；文件内按“架构概览 → 分层架构 → 模块化 → 数据安全”顺序。

## B03：多设备窗口环境

- **Batch ID：** B03
- **文件：**
  - `窗口方向-多设备窗口形态.html`
  - `窗口模式-多设备窗口形态.html`
  - `窗口沉浸式-多设备窗口形态.html`
- **主题：** 不同设备上的窗口方向、窗口模式和沉浸式窗口空间。
- **与其他批次的依赖关系：** 依赖 B01 的体验目标及 B02 的架构边界；为 B04 的布局决策提供窗口尺寸、方向和可用区域前提。
- **推荐处理顺序：** 在 B02 后、B04 前处理；文件内按“方向 → 模式 → 沉浸式”顺序。

## B04：响应式界面布局

- **Batch ID：** B04

- **与其他批次的依赖关系：** 依赖 B03 对窗口环境的定义；其布局策略被 B05 的设备功能和设置界面适配复用。
- **推荐处理顺序：** 在 B03 后处理；文件内按“概览 → 响应式布局 → 屏幕类型 → 页面 → 组件”顺序。
